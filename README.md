# Site freelance (Astro)

1. npm install
2. npm run dev (test local)
3. Remplacer les [À COMPLÉTER], VOTRE_CLE_WEB3FORMS, VOTRE_SITEKEY_HCAPTCHA, et site dans astro.config.mjs
4. git push sur main : le déploiement est automatique (GitHub Actions)
5. Remplacer [domaine] dans les mentions légales (attributs data-d inclus). Utiliser une adresse publique (alias) différente de la boîte réelle reliée à Web3Forms.
6. Images : déposer les fichiers dans public/images/ (webp ou jpg, moins de 300 Ko), puis modifier la balise img (src, alt, width, height).
